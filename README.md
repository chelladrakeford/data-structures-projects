# Data Structures and Programming Projects

A collection of academic programming projects developed using Java, with an emphasis on data structures, object-oriented programming, algorithms, and problem-solving.

## Projects

### 1. Moc Mart Inventory and Sales Management System
A Java-based inventory management project demonstrating object-oriented programming, arrays of objects, product management, and binary search.

### 2. Grade Book Management System
A Java application for managing student records and weighted grades, incorporating linked-list operations and object-oriented programming.

### 3. Image Processing and Recursion
A Java project exploring pixel representation, two-dimensional arrays, nested loops, and recursive methods.

## Technologies
- Java
- Object-Oriented Programming
- Arrays and Linked Lists
- Binary Search
- Recursion
- Git and GitHub

## About
These projects were developed as part of my Computer Science coursework at Florida Southern College.
